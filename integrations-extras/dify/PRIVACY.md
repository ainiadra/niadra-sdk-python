# Privacy

This plugin sends to the Niadra API of your space, with the source key you configure:

- the customer's handle (phone, WhatsApp id, e-mail or id) and the conversation id the app maps;
- the customer's message and the agent's reply of each turn you pass to Get context and Record reply;
- the queries the model makes with the history tools.

It stores nothing itself. What Niadra keeps, for how long and who can read it is set by your space's
policy; see https://niadra.com and https://docs.niadra.com/en.
